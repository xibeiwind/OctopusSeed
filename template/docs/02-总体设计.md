## 1. 架构总览

<分层与依赖方向；文本图亦可。示例：>

```
入口（CLI / GUI / 服务宿主）
   ↓  仅依赖
应用层（用例编排 / 生命周期）
   ↓  仅依赖
领域层（模型 / 状态机 / 规则，无平台依赖）
   ↑  由适配器实现
平台 / 基础设施层（OS API、网络、存储、第三方 SDK）
```

**依赖方向不可逆**：上层依赖下层，下层不知道上层；跨层反向调用一律经接口注入。
