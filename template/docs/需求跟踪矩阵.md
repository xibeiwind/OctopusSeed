# 需求跟踪矩阵（RTM）

> **作用**：需求 ↔ 工作包的**双向追溯**唯一真相源（`CONTRIBUTING.md` §5 / §9.1 R-Plan-2）。
> 每完成一个工作包，PR 合并后**与阶段计划回填同批提交**，更新本表「状态」与「验收/证据」列。
> 需求 ID 来自 `01-需求规格说明书.md` 的 §/R 编号，**不重编号**。

---

## 状态图例

| 标记 | 含义 |
|---|---|
| ⬜ | 未开始 |
| 🔄 | 进行中 |
| ✅ | 已完成（附 PR 号与证据） |
| ⏸ | 阻塞（注明依赖） |
| ❌ | 取消 / 转为范围外（见 `范围边界清单.md`） |
