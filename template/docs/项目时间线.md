# 项目时间线

> **作用**：按日期总览「每一步做了什么」。
> **机械事实的唯一权威处**（`CONTRIBUTING.md` §9.1 **R-Plan-6**）：门禁数字 / PR 号 / 计数 / 日期等机械事实**只在本文档 §1 写最新值**——阶段计划只写本包增量，收口评审只写时点快照，其余处只引用或省略。
> **逐包机械列请勿手抄**，由脚本从 git 起草：
> ```powershell
> powershell -ExecutionPolicy Bypass -File tools/governance-check.ps1 -Timeline P0
> ```
> 直接推出首见日期 / 逐包提交数 / 逐包 PR。**摘要列刻意留人工。**

## 三、使用说明

1. **只写最新值**：同一机械事实（如测试总数）只在本表更新，其它文档不重复抄写（避免多份而漂移）。
2. **增量视图**：阶段执行计划 §6 只写**本阶段本包增量**；收口评审写**时点快照**。
3. **摘要人工**：脚本能起草日期 / 包号 / PR，但"做了什么、为什么"由人写。

> **判据依赖的形状**（看板按首列形态识别，见 `CONTRIBUTING.md` §10）：§一 首列必须是 `YYYY-MM-DD`；§二 首列必须是 `P<数字>`。
> **阶段状态**用 `CONTRIBUTING.md` §9.3 的码点字符（看板据此判定「当前进行中的阶段」并推出"下一步"）。
